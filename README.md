# Odina 3D Website

Premium interactive website concept for Odina cake shop.

## Stack
- React
- Vite
- Three.js / React Three Fiber
- Drei
- Framer Motion

## Run locally
```bash
npm install
npm run dev
```

## Production build
```bash
npm run build
```

The first version includes a responsive premium landing page and a procedural interactive 3D signature cake that can be rotated by dragging.
